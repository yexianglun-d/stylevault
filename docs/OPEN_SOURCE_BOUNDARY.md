# StyleVault 开源边界

## 可以开源

- 风格结构化数据、标签体系、7 维度拆解字段。
- 本地推荐、对比、混合、学习训练逻辑。
- CSS Variables、Tailwind 主题、Prompt 模板的生成方式。
- 不包含授权风险的原创示例、抽象预览和项目文档。

## 不放进仓库

- 未授权的产品截图、竞品截图、品牌素材、付费字体文件。
- 真实用户上传图片、识别历史、收藏数据。
- OpenAI 或其他模型服务商 API Key。
- 私有部署域名、内部分析 token、日志平台 DSN。

## AI 接入原则

前端只负责收集用户意图和展示结果。真实模型调用应放在服务端代理，服务端负责 Key 管理、限流、日志脱敏和失败兜底。未配置服务端时，产品使用本地规则完成推荐与候选识别，不伪装成真实 AI 已接入。

## 贡献数据要求

新增风格必须补齐 7 个形态维度、至少 4 个配色 token、使用场景、避免场景、Prompt、CSS 片段和笔记路径。来源参考只写公开链接或书目，不复制受版权保护的长文本。
