# 冷静后台 / Admin Calm

## 一句话理解

低噪声色彩、清晰分栏和高密度表格适合长时间工作。

## 适合什么页面

- 后台管理
- 数据仪表盘

## 不适合什么页面

- 极简作品集
- 强留白品牌页

## 常见错误

- 只套用颜色，没有同步 小圆角、无衬线、均匀层级、柔和弥散 等形态特征。
- 在 极简作品集、强留白品牌页 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
