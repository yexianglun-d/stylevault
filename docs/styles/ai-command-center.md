# AI 指挥台 / AI Command Center

## 一句话理解

暗色工作台、状态芯片、发光边框和密集工具区适合 AI 产品。

## 适合什么页面

- AI 工具页
- 数据仪表盘
- 开发者工具

## 不适合什么页面

- 极简作品集
- 强留白品牌页

## 7 维度拆解

- 形状：小圆角、大圆角。形状以小圆角、大圆角为主，用来控制风格识别度。
- 排版：无衬线、等宽。排版以无衬线、等宽为主，用来控制风格识别度。
- 光影：发光、柔和弥散。光影以发光、柔和弥散为主，用来控制风格识别度。
- 空间：紧凑、多层深度。空间以紧凑、多层深度为主，用来控制风格识别度。
- 动效：平滑缓动、快速。动效以平滑缓动、快速为主，用来控制风格识别度。
- 色彩：冷色、对比。色彩以冷色、对比为主，用来控制风格识别度。
- 质感：发光边框、细线。质感以发光边框、细线为主，用来控制风格识别度。

- background / 背景色：#090E1A
- primary / 主色：#8B5CF6
- accent / 强调色：#2DD4BF
- surface / 表面色：#E2E8F0

## AI Prompt 写法

请使用 AI Command Center / AI 指挥台 风格实现页面。核心视觉：暗色工作台、状态芯片、发光边框和密集工具区适合 AI 产品。。请使用 AI、控制台、暗色、工具、状态，配色以 #090E1A、#8B5CF6、#2DD4BF、#E2E8F0 为主，CSS 方向包含 radius 16px、shadow 0 24px 80px rgba(45,212,191,.12)、border 1px solid rgba(139,92,246,.38)。

关键词：AI Command Center AI 指挥台，AI，控制台，暗色，工具，状态

## 常见错误

- 只套用颜色，没有同步 小圆角、大圆角、无衬线、等宽 等形态特征。
- 在 极简作品集、强留白品牌页 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
