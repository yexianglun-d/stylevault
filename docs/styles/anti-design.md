# 反设计 / Anti Design

## 一句话理解

故意打破网格、比例和常规美感，形成强烈态度。

## 适合什么页面

- 营销活动页
- 个人作品集

## 不适合什么页面

- 极简作品集
- 强留白品牌页

## 7 维度拆解

- 形状：直角、不规则。形状以直角、不规则为主，用来控制风格识别度。
- 排版：极端对比、装饰体。排版以极端对比、装饰体为主，用来控制风格识别度。
- 光影：硬投影。光影以硬投影为主，用来控制风格识别度。
- 空间：密集、不对称。空间以密集、不对称为主，用来控制风格识别度。
- 动效：快速。动效以快速为主，用来控制风格识别度。
- 色彩：高饱和、对比。色彩以高饱和、对比为主，用来控制风格识别度。
- 质感：粗线。质感以粗线为主，用来控制风格识别度。

## 配色方案

- background / 背景色：#FFFFFF
- primary / 主色：#111111
- accent / 强调色：#FF0000
- surface / 表面色：#0000FF

## CSS 实现要点

- 反设计 核心容器：`.sv-anti-design {
  background: #FF0000;
  color: #111111;
  border: 4px solid #111111;
  border-radius: 2px;
  box-shadow: -8px 14px 0 #0000FF;
}`

## AI Prompt 写法

请使用 Anti Design / 反设计 风格实现页面。核心视觉：故意打破网格、比例和常规美感，形成强烈态度。。请使用 反设计、错位、强冲击、实验、非对称，配色以 #FFFFFF、#111111、#FF0000、#0000FF 为主，CSS 方向包含 radius 2px、shadow -8px 14px 0 #0000FF、border 4px solid #111111。

关键词：Anti Design 反设计，反设计，错位，强冲击，实验，非对称

## 常见错误

- 只套用颜色，没有同步 直角、不规则、极端对比、装饰体 等形态特征。
- 在 极简作品集、强留白品牌页 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
