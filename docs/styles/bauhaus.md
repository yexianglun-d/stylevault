# 包豪斯 / Bauhaus

## 一句话理解

基础几何、红黄蓝黑和理性构图形成现代主义秩序。

## 适合什么页面

- 个人作品集
- SaaS 官网
- 营销活动页

## 不适合什么页面

- 超高密度表格
- 复杂权限后台

## 7 维度拆解

- 形状：圆形、直角。形状以圆形、直角为主，用来控制风格识别度。
- 排版：无衬线、均匀层级。排版以无衬线、均匀层级为主，用来控制风格识别度。
- 光影：硬投影。光影以硬投影为主，用来控制风格识别度。
- 空间：网格、不对称。空间以网格、不对称为主，用来控制风格识别度。
- 动效：快速。动效以快速为主，用来控制风格识别度。
- 色彩：三色、对比。色彩以三色、对比为主，用来控制风格识别度。
- 质感：粗线。质感以粗线为主，用来控制风格识别度。

- surface / 表面色：#F77F00

## 常见错误

- 只套用颜色，没有同步 圆形、直角、无衬线、均匀层级 等形态特征。
- 在 超高密度表格、复杂权限后台 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
