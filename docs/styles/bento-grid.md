# Bento 网格 / Bento Grid

## 一句话理解

用模块化卡片网格组织功能和信息，适合产品能力展示。

## 适合什么页面

- SaaS 官网
- AI 工具页
- 个人作品集
- 定价页

## 不适合什么页面

- 超高密度表格
- 复杂权限后台

## 7 维度拆解

- 形状：大圆角。形状以大圆角为主，用来控制风格识别度。
- 排版：无衬线、均匀层级。排版以无衬线、均匀层级为主，用来控制风格识别度。
- 光影：柔和弥散。光影以柔和弥散为主，用来控制风格识别度。
- 空间：网格、适中。空间以网格、适中为主，用来控制风格识别度。
- 动效：平滑缓动。动效以平滑缓动为主，用来控制风格识别度。
- 色彩：三色、冷色。色彩以三色、冷色为主，用来控制风格识别度。
- 质感：光滑。质感以光滑为主，用来控制风格识别度。

## 配色方案

- background / 背景色：#F8FAFC
- primary / 主色：#0F172A
- accent / 强调色：#2563EB
- surface / 表面色：#E2E8F0

## CSS 实现要点

- Bento 网格 核心容器：`.sv-bento-grid {
  background: #FFFFFF;
  color: #0F172A;
  border: 1px solid #E2E8F0;
  border-radius: 18px;
  box-shadow: 0 22px 50px rgba(15,23,42,.1);
}`

关键词：Bento Grid Bento 网格，Bento，卡片，网格，SaaS，浅色

## 常见错误

- 只套用颜色，没有同步 大圆角、无衬线、均匀层级、柔和弥散 等形态特征。
- 在 超高密度表格、复杂权限后台 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
