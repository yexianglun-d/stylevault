# 粗野主义 / Brutalism

## 一句话理解

大色块、硬边框、强对比和反精致布局制造直接冲击。

## 适合什么页面

- 个人作品集
- 营销活动页
- SaaS 官网

## 不适合什么页面

- 极简作品集
- 强留白品牌页

## 7 维度拆解

- 形状：直角。形状以直角为主，用来控制风格识别度。
- 排版：无衬线、大标题主导。排版以无衬线、大标题主导为主，用来控制风格识别度。
- 光影：硬投影。光影以硬投影为主，用来控制风格识别度。
- 空间：密集、不对称。空间以密集、不对称为主，用来控制风格识别度。
- 动效：快速。动效以快速为主，用来控制风格识别度。
- 色彩：高饱和、对比。色彩以高饱和、对比为主，用来控制风格识别度。
- 质感：粗线、无纹理。质感以粗线、无纹理为主，用来控制风格识别度。

## 配色方案

- background / 背景色：#F5F000
- primary / 主色：#000000
- accent / 强调色：#FF3B30
- surface / 表面色：#FFFFFF

## CSS 实现要点

- 粗野主义 核心容器：`.sv-brutalism {
  background: #FFFFFF;
  color: #000000;
  border: 3px solid #000000;
  border-radius: 0px;
  box-shadow: 10px 10px 0 #000000;
}`

关键词：Brutalism 粗野主义，粗野，硬边框，高对比，大字，反常规

## 常见错误

- 只套用颜色，没有同步 直角、无衬线、大标题主导、硬投影 等形态特征。
- 在 极简作品集、强留白品牌页 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
