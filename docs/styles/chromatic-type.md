# 色差字体 / Chromatic Type

## 一句话理解

用色差偏移、大标题和轻微故障感强化视觉记忆。

## 适合什么页面

- 个人作品集
- 营销活动页
- AI 工具页

## 不适合什么页面

- 超高密度表格
- 复杂权限后台

## 7 维度拆解

- 形状：小圆角。形状以小圆角为主，用来控制风格识别度。
- 排版：大标题主导、极端对比。排版以大标题主导、极端对比为主，用来控制风格识别度。
- 光影：发光、硬投影。光影以发光、硬投影为主，用来控制风格识别度。
- 空间：适中、不对称。空间以适中、不对称为主，用来控制风格识别度。
- 动效：机械步进、快速。动效以机械步进、快速为主，用来控制风格识别度。
- 色彩：对比、高饱和。色彩以对比、高饱和为主，用来控制风格识别度。
- 质感：发光边框。质感以发光边框为主，用来控制风格识别度。

## 配色方案

- background / 背景色：#09090B
- primary / 主色：#FAFAFA
- accent / 强调色：#F43F5E
- surface / 表面色：#22D3EE

## CSS 实现要点

- 色差字体 核心容器：`.sv-chromatic-type {
  background: #18181B;
  color: #FAFAFA;
  border: 1px solid #3F3F46;
  border-radius: 10px;
  box-shadow: 8px 0 0 rgba(34,211,238,.45), -8px 0 0 rgba(244,63,94,.45);
}`

## AI Prompt 写法

请使用 Chromatic Type / 色差字体 风格实现页面。核心视觉：用色差偏移、大标题和轻微故障感强化视觉记忆。。请使用 色差、故障、大标题、实验、暗色，配色以 #09090B、#FAFAFA、#F43F5E、#22D3EE 为主，CSS 方向包含 radius 10px、shadow 8px 0 0 rgba(34,211,238,.45), -8px 0 0 rgba(244,63,94,.45)、border 1px solid #3F3F46。

关键词：Chromatic Type 色差字体，色差，故障，大标题，实验，暗色

## 常见错误

- 只套用颜色，没有同步 小圆角、大标题主导、极端对比、发光 等形态特征。
- 在 超高密度表格、复杂权限后台 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
