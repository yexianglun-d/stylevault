# 黏土拟态 / Claymorphism

## 一句话理解

厚重圆角、柔和阴影和高饱和色块形成玩具般黏土感。

## 适合什么页面

- 移动端首页
- 营销活动页
- 登录页

## 不适合什么页面

- 超高密度表格
- 复杂权限后台

## 7 维度拆解

- 形状：大圆角、有机曲线。形状以大圆角、有机曲线为主，用来控制风格识别度。
- 排版：无衬线、大标题主导。排版以无衬线、大标题主导为主，用来控制风格识别度。
- 光影：柔和弥散。光影以柔和弥散为主，用来控制风格识别度。
- 空间：适中。空间以适中为主，用来控制风格识别度。
- 动效：弹性弹跳。动效以弹性弹跳为主，用来控制风格识别度。
- 色彩：多彩、高饱和。色彩以多彩、高饱和为主，用来控制风格识别度。
- 质感：黏土。质感以黏土为主，用来控制风格识别度。

## 常见错误

- 只套用颜色，没有同步 大圆角、有机曲线、无衬线、大标题主导 等形态特征。
- 在 超高密度表格、复杂权限后台 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
