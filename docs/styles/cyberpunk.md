# 赛博朋克 / Cyberpunk

## 一句话理解

暗色背景、霓虹描边、斜切形状和高对比营造都市未来感。

## 适合什么页面

- 营销活动页
- 开发者工具
- AI 工具页

## 不适合什么页面

- 极简作品集
- 强留白品牌页

## 常见错误

- 只套用颜色，没有同步 直角、不规则、等宽、大标题主导 等形态特征。
- 在 极简作品集、强留白品牌页 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
