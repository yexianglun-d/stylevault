# 数据终端 / Data Terminal

## 一句话理解

等宽字体、暗色面板、细网格和高密度数据组成工程终端感。

## 适合什么页面

- 数据仪表盘
- 开发者工具
- 后台管理

## 不适合什么页面

- 极简作品集
- 强留白品牌页

## 7 维度拆解

- 形状：直角、小圆角。形状以直角、小圆角为主，用来控制风格识别度。
- 排版：等宽。排版以等宽为主，用来控制风格识别度。
- 光影：发光。光影以发光为主，用来控制风格识别度。
- 空间：密集、网格。空间以密集、网格为主，用来控制风格识别度。
- 动效：机械步进、快速。动效以机械步进、快速为主，用来控制风格识别度。
- 色彩：单色、冷色。色彩以单色、冷色为主，用来控制风格识别度。
- 质感：网格、细线。质感以网格、细线为主，用来控制风格识别度。

## 配色方案

- background / 背景色：#07110B
- primary / 主色：#22C55E
- accent / 强调色：#84CC16
- surface / 表面色：#16321F

请使用 Data Terminal / 数据终端 风格实现页面。核心视觉：等宽字体、暗色面板、细网格和高密度数据组成工程终端感。。请使用 终端、等宽、暗色、数据、高密度，配色以 #07110B、#22C55E、#84CC16、#16321F 为主，CSS 方向包含 radius 8px、shadow 0 20px 60px rgba(34,197,94,.12)、border 1px solid #1F5130。

关键词：Data Terminal 数据终端，终端，等宽，暗色，数据，高密度

## 常见错误

- 只套用颜色，没有同步 直角、小圆角、等宽、发光 等形态特征。
- 在 极简作品集、强留白品牌页 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
