# 编辑部衬线 / Editorial Serif

## 一句话理解

以大标题、衬线字体和杂志式节奏制造高级内容感。

## 适合什么页面

- 个人作品集
- 营销活动页
- SaaS 官网

## 不适合什么页面

- 超高密度表格
- 复杂权限后台

## 7 维度拆解

- 形状：直角、小圆角。形状以直角、小圆角为主，用来控制风格识别度。
- 排版：衬线、大标题主导。排版以衬线、大标题主导为主，用来控制风格识别度。
- 光影：无阴影。光影以无阴影为主，用来控制风格识别度。
- 空间：极多留白、不对称。空间以极多留白、不对称为主，用来控制风格识别度。
- 动效：慢速。动效以慢速为主，用来控制风格识别度。
- 色彩：双色、暖色。色彩以双色、暖色为主，用来控制风格识别度。
- 质感：纸张。质感以纸张为主，用来控制风格识别度。

## 配色方案

- background / 背景色：#F4EFE7
- primary / 主色：#211A16
- accent / 强调色：#8B3A2B
- surface / 表面色：#C8B6A6

## CSS 实现要点

- 编辑部衬线 核心容器：`.sv-editorial-serif {
  background: #FFF9F0;
  color: #211A16;
  border: 1px solid #C8B6A6;
  border-radius: 4px;
  box-shadow: 0 20px 55px rgba(33,26,22,.12);
}`

## AI Prompt 写法

请使用 Editorial Serif / 编辑部衬线 风格实现页面。核心视觉：以大标题、衬线字体和杂志式节奏制造高级内容感。。请使用 衬线、杂志、作品集、大标题、留白，配色以 #F4EFE7、#211A16、#8B3A2B、#C8B6A6 为主，CSS 方向包含 radius 4px、shadow 0 20px 55px rgba(33,26,22,.12)、border 1px solid #C8B6A6。

关键词：Editorial Serif 编辑部衬线，衬线，杂志，作品集，大标题，留白

## 常见错误

- 只套用颜色，没有同步 直角、小圆角、衬线、大标题主导 等形态特征。
- 在 超高密度表格、复杂权限后台 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
