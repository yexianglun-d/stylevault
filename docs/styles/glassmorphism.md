# 玻璃拟态 / Glassmorphism

## 一句话理解

用半透明面板、背景模糊和高光边框营造磨砂玻璃层次。

## 适合什么页面

- 登录页
- 个人作品集
- AI 工具页
- SaaS 官网

## 不适合什么页面

- 超高密度表格
- 复杂权限后台

## 7 维度拆解

- 形状：大圆角。形状以大圆角为主，用来控制风格识别度。
- 排版：无衬线、均匀层级。排版以无衬线、均匀层级为主，用来控制风格识别度。
- 光影：柔和弥散、玻璃反光。光影以柔和弥散、玻璃反光为主，用来控制风格识别度。
- 空间：适中、多层深度。空间以适中、多层深度为主，用来控制风格识别度。
- 动效：平滑缓动、中速。动效以平滑缓动、中速为主，用来控制风格识别度。
- 色彩：渐变、冷色。色彩以渐变、冷色为主，用来控制风格识别度。
- 质感：玻璃、磨砂。质感以玻璃、磨砂为主，用来控制风格识别度。

- background / 背景色：#0F172A

  background: rgba(255,255,255,.16);

## AI Prompt 写法

请使用 Glassmorphism / 玻璃拟态 风格实现页面。核心视觉：用半透明面板、背景模糊和高光边框营造磨砂玻璃层次。。请使用 毛玻璃、半透明、冷色、渐变、柔和阴影、大圆角，配色以 #0F172A、#6366F1、#22D3EE、#FFFFFF 为主，CSS 方向包含 radius 24px、shadow 0 24px 80px rgba(15,23,42,.38)、border 1px solid rgba(255,255,255,.28)。

关键词：Glassmorphism 玻璃拟态，毛玻璃，半透明，冷色，渐变，柔和阴影

## 常见错误

- 只套用颜色，没有同步 大圆角、无衬线、均匀层级、柔和弥散 等形态特征。
- 在 超高密度表格、复杂权限后台 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
