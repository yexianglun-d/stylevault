# 网格核心 / Gridcore

## 一句话理解

明显网格线、坐标标注和模块切割带来设计稿般的结构感。

## 适合什么页面

- 开发者工具
- 数据仪表盘
- 文档站

## 不适合什么页面

- 极简作品集
- 强留白品牌页

## 7 维度拆解

- 形状：直角。形状以直角为主，用来控制风格识别度。
- 排版：等宽、均匀层级。排版以等宽、均匀层级为主，用来控制风格识别度。
- 光影：无阴影。光影以无阴影为主，用来控制风格识别度。
- 空间：网格、分栏。空间以网格、分栏为主，用来控制风格识别度。
- 动效：快速。动效以快速为主，用来控制风格识别度。
- 色彩：低饱和、单色。色彩以低饱和、单色为主，用来控制风格识别度。
- 质感：网格、细线。质感以网格、细线为主，用来控制风格识别度。

## 配色方案

- background / 背景色：#F8FAFC
- primary / 主色：#0F172A
- accent / 强调色：#475569
- surface / 表面色：#CBD5E1

  background: #FFFFFF;

  border-radius: 4px;
  box-shadow: none;

关键词：Gridcore 网格核心，网格，坐标，结构，工具，细线

## 常见错误

- 只套用颜色，没有同步 直角、等宽、均匀层级、无阴影 等形态特征。
- 在 极简作品集、强留白品牌页 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
