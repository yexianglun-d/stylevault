# 全息渐变 / Holographic

## 一句话理解

虹彩渐变、透明层和柔光让界面像未来展品。

## 适合什么页面

- 营销活动页
- 个人作品集
- AI 工具页

## 不适合什么页面

- 超高密度表格
- 复杂权限后台

## 7 维度拆解

- 形状：大圆角。形状以大圆角为主，用来控制风格识别度。
- 排版：无衬线、大标题主导。排版以无衬线、大标题主导为主，用来控制风格识别度。
- 光影：发光、玻璃反光。光影以发光、玻璃反光为主，用来控制风格识别度。
- 空间：多层深度。空间以多层深度为主，用来控制风格识别度。
- 动效：流体、慢速。动效以流体、慢速为主，用来控制风格识别度。
- 色彩：全息、渐变。色彩以全息、渐变为主，用来控制风格识别度。
- 质感：玻璃、发光边框。质感以玻璃、发光边框为主，用来控制风格识别度。

## 配色方案

- background / 背景色：#10111A
- primary / 主色：#A78BFA
- accent / 强调色：#5EEAD4
- surface / 表面色：#F0ABFC

## CSS 实现要点

- 全息渐变 核心容器：`.sv-holographic {
  background: linear-gradient(135deg, rgba(167,139,250,.7), rgba(94,234,212,.55), rgba(240,171,252,.65));
  color: #FFFFFF;
  border: 1px solid rgba(255,255,255,.4);
  border-radius: 24px;
  box-shadow: 0 30px 90px rgba(167,139,250,.35);
}`

关键词：Holographic 全息渐变，全息，渐变，虹彩，未来，柔光

## 常见错误

- 只套用颜色，没有同步 大圆角、无衬线、大标题主导、发光 等形态特征。
- 在 超高密度表格、复杂权限后台 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
