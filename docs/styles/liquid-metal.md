# 液态金属 / Liquid Metal

## 一句话理解

银色渐变、高光反射和流体边缘组成未来材质感。

## 适合什么页面

- 营销活动页
- AI 工具页
- 个人作品集

## 不适合什么页面

- 超高密度表格
- 复杂权限后台

## 7 维度拆解

- 形状：有机曲线、大圆角。形状以有机曲线、大圆角为主，用来控制风格识别度。
- 排版：无衬线、大标题主导。排版以无衬线、大标题主导为主，用来控制风格识别度。
- 光影：金属高光、玻璃反光。光影以金属高光、玻璃反光为主，用来控制风格识别度。
- 空间：多层深度。空间以多层深度为主，用来控制风格识别度。
- 动效：流体、慢速。动效以流体、慢速为主，用来控制风格识别度。
- 色彩：金属、全息。色彩以金属、全息为主，用来控制风格识别度。
- 质感：金属、光滑。质感以金属、光滑为主，用来控制风格识别度。

## 常见错误

- 只套用颜色，没有同步 有机曲线、大圆角、无衬线、大标题主导 等形态特征。
- 在 超高密度表格、复杂权限后台 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
