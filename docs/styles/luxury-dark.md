# 暗黑奢华 / Luxury Dark

## 一句话理解

深色底、金色强调、细腻边框和克制留白构成高级感。

## 适合什么页面

- 个人作品集
- 定价页
- 营销活动页

## 不适合什么页面

- 超高密度表格
- 复杂权限后台

## 7 维度拆解

- 形状：小圆角。形状以小圆角为主，用来控制风格识别度。
- 排版：衬线、大标题主导。排版以衬线、大标题主导为主，用来控制风格识别度。
- 光影：金属高光、柔和弥散。光影以金属高光、柔和弥散为主，用来控制风格识别度。
- 空间：极多留白。空间以极多留白为主，用来控制风格识别度。
- 动效：慢速。动效以慢速为主，用来控制风格识别度。
- 色彩：暖色、对比。色彩以暖色、对比为主，用来控制风格识别度。
- 质感：金属、细线。质感以金属、细线为主，用来控制风格识别度。

## 配色方案

- background / 背景色：#0E0B08
- primary / 主色：#D6B56D
- accent / 强调色：#F8F1E5
- surface / 表面色：#2A2118

## 常见错误

- 只套用颜色，没有同步 小圆角、衬线、大标题主导、金属高光 等形态特征。
- 在 超高密度表格、复杂权限后台 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
