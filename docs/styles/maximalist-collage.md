# 极繁拼贴 / Maximalist Collage

## 一句话理解

多层图形、强色彩、重叠排版和高密度信息制造视觉兴奋。

## 适合什么页面

- 营销活动页
- 个人作品集

## 不适合什么页面

- 极简作品集
- 强留白品牌页

## 7 维度拆解

- 形状：不规则。形状以不规则为主，用来控制风格识别度。
- 排版：装饰体、极端对比。排版以装饰体、极端对比为主，用来控制风格识别度。
- 光影：硬投影。光影以硬投影为主，用来控制风格识别度。
- 空间：密集、不对称。空间以密集、不对称为主，用来控制风格识别度。
- 动效：快速、弹性弹跳。动效以快速、弹性弹跳为主，用来控制风格识别度。
- 色彩：多彩、高饱和。色彩以多彩、高饱和为主，用来控制风格识别度。
- 质感：粗线、噪点。质感以粗线、噪点为主，用来控制风格识别度。

## 配色方案

- background / 背景色：#111827
- primary / 主色：#F97316
- accent / 强调色：#A3E635
- surface / 表面色：#EC4899

## CSS 实现要点

- 极繁拼贴 核心容器：`.sv-maximalist-collage {
  background: #F97316;
  color: #FFFFFF;
  border: 2px solid #FFFFFF;
  border-radius: 12px;
  box-shadow: -10px 12px 0 #EC4899, 12px -8px 0 #A3E635;
}`

## 常见错误

- 只套用颜色，没有同步 不规则、装饰体、极端对比、硬投影 等形态特征。
- 在 极简作品集、强留白品牌页 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
