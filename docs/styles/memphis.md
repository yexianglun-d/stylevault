# 孟菲斯 / Memphis

## 一句话理解

几何图案、鲜艳配色和随性排布组成 80 年代装饰风格。

## 适合什么页面

- 营销活动页
- 个人作品集
- 移动端首页

## 不适合什么页面

- 极简作品集
- 强留白品牌页

## 常见错误

- 只套用颜色，没有同步 不规则、圆形、无衬线、装饰体 等形态特征。
- 在 极简作品集、强留白品牌页 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
