# 黑白系统 / Monochrome System

## 一句话理解

用黑白灰、细线和密集控件表达专业工具感。

## 适合什么页面

- 后台管理
- 开发者工具
- 文档站
- 数据仪表盘

## 不适合什么页面

- 极简作品集
- 强留白品牌页

## 7 维度拆解

- 形状：小圆角、直角。形状以小圆角、直角为主，用来控制风格识别度。
- 排版：无衬线、均匀层级。排版以无衬线、均匀层级为主，用来控制风格识别度。
- 光影：无阴影。光影以无阴影为主，用来控制风格识别度。
- 空间：紧凑、分栏。空间以紧凑、分栏为主，用来控制风格识别度。
- 动效：快速。动效以快速为主，用来控制风格识别度。
- 色彩：单色。色彩以单色为主，用来控制风格识别度。
- 质感：细线、无纹理。质感以细线、无纹理为主，用来控制风格识别度。

## 配色方案

- background / 背景色：#FFFFFF
- primary / 主色：#0A0A0A
- accent / 强调色：#737373
- surface / 表面色：#E5E5E5

## CSS 实现要点

- 黑白系统 核心容器：`.sv-monochrome-system {
  background: #F7F7F7;
  color: #0A0A0A;
  border: 1px solid #D4D4D4;
  border-radius: 8px;
  box-shadow: none;
}`

关键词：Monochrome System 黑白系统，黑白，细线，工具，高可读，后台

## 常见错误

- 只套用颜色，没有同步 小圆角、直角、无衬线、均匀层级 等形态特征。
- 在 极简作品集、强留白品牌页 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
