# 新粗野主义 / Neo Brutalism

## 一句话理解

保留粗边框和硬投影，但用更友好的圆角和色彩做现代化。

## 适合什么页面

- 开发者工具
- AI 工具页
- 定价页
- 营销活动页

## 不适合什么页面

- 超高密度表格
- 复杂权限后台

## 7 维度拆解

- 形状：小圆角、直角。形状以小圆角、直角为主，用来控制风格识别度。
- 排版：无衬线、大标题主导。排版以无衬线、大标题主导为主，用来控制风格识别度。
- 光影：硬投影。光影以硬投影为主，用来控制风格识别度。
- 空间：网格、适中。空间以网格、适中为主，用来控制风格识别度。
- 动效：弹性弹跳、快速。动效以弹性弹跳、快速为主，用来控制风格识别度。
- 色彩：多彩、高饱和。色彩以多彩、高饱和为主，用来控制风格识别度。
- 质感：粗线。质感以粗线为主，用来控制风格识别度。

## 配色方案

- background / 背景色：#FFF6D6
- primary / 主色：#111111
- accent / 强调色：#4ADE80
- surface / 表面色：#60A5FA

关键词：Neo Brutalism 新粗野主义，新粗野，硬投影，高饱和，圆角，卡片

## 常见错误

- 只套用颜色，没有同步 小圆角、直角、无衬线、大标题主导 等形态特征。
- 在 超高密度表格、复杂权限后台 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
