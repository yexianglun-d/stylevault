# 新未来主义 / Neo Futurism

## 一句话理解

大面积暗色、几何切面、冷光和克制排版塑造高级科技感。

## 适合什么页面

- SaaS 官网
- AI 工具页
- 营销活动页

## 不适合什么页面

- 超高密度表格
- 复杂权限后台

## 7 维度拆解

- 形状：小圆角、不规则。形状以小圆角、不规则为主，用来控制风格识别度。
- 排版：无衬线、大标题主导。排版以无衬线、大标题主导为主，用来控制风格识别度。
- 光影：发光、柔和弥散。光影以发光、柔和弥散为主，用来控制风格识别度。
- 空间：极多留白、多层深度。空间以极多留白、多层深度为主，用来控制风格识别度。
- 动效：平滑缓动、中速。动效以平滑缓动、中速为主，用来控制风格识别度。
- 色彩：冷色、对比。色彩以冷色、对比为主，用来控制风格识别度。
- 质感：金属、细线。质感以金属、细线为主，用来控制风格识别度。

关键词：Neo Futurism 新未来主义，未来，几何，暗色，冷光，高端

## 常见错误

- 只套用颜色，没有同步 小圆角、不规则、无衬线、大标题主导 等形态特征。
- 在 超高密度表格、复杂权限后台 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
