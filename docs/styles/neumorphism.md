# 新拟态 / Neumorphism

## 一句话理解

通过内外双阴影让控件像从背景中浮起或凹陷。

## 适合什么页面

- 移动端首页
- 登录页
- AI 工具页

## 不适合什么页面

- 超高密度表格
- 复杂权限后台

## 7 维度拆解

- 形状：大圆角、全圆角。形状以大圆角、全圆角为主，用来控制风格识别度。
- 排版：无衬线。排版以无衬线为主，用来控制风格识别度。
- 光影：柔和弥散、内阴影。光影以柔和弥散、内阴影为主，用来控制风格识别度。
- 空间：适中。空间以适中为主，用来控制风格识别度。
- 动效：平滑缓动。动效以平滑缓动为主，用来控制风格识别度。
- 色彩：单色、低饱和。色彩以单色、低饱和为主，用来控制风格识别度。
- 质感：光滑。质感以光滑为主，用来控制风格识别度。

## 配色方案

- background / 背景色：#E7ECF3
- primary / 主色：#64748B
- accent / 强调色：#94A3B8
- surface / 表面色：#FFFFFF

## CSS 实现要点

- 新拟态 核心容器：`.sv-neumorphism {
  background: #E7ECF3;
  color: #334155;
  border: 1px solid rgba(255,255,255,.45);
  border-radius: 26px;
  box-shadow: 18px 18px 36px #c5c9cf, -18px -18px 36px #ffffff;
}`

关键词：Neumorphism 新拟态，新拟态，柔和阴影，低对比，浅色，圆润

## 常见错误

- 只套用颜色，没有同步 大圆角、全圆角、无衬线、柔和弥散 等形态特征。
- 在 超高密度表格、复杂权限后台 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
