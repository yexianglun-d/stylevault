# 有机流形 / Organic Morphic

## 一句话理解

有机曲线、柔软色块和流体布局营造自然生长感。

## 适合什么页面

- 移动端首页
- 个人作品集
- 营销活动页

## 不适合什么页面

- 超高密度表格
- 复杂权限后台

## 7 维度拆解

- 形状：有机曲线、不规则。形状以有机曲线、不规则为主，用来控制风格识别度。
- 排版：无衬线。排版以无衬线为主，用来控制风格识别度。
- 光影：柔和弥散。光影以柔和弥散为主，用来控制风格识别度。
- 空间：极多留白、不对称。空间以极多留白、不对称为主，用来控制风格识别度。
- 动效：流体、慢速。动效以流体、慢速为主，用来控制风格识别度。
- 色彩：低饱和、暖色。色彩以低饱和、暖色为主，用来控制风格识别度。
- 质感：光滑、无纹理。质感以光滑、无纹理为主，用来控制风格识别度。

## 常见错误

- 只套用颜色，没有同步 有机曲线、不规则、无衬线、柔和弥散 等形态特征。
- 在 超高密度表格、复杂权限后台 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
