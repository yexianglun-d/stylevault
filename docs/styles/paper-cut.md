# 纸片剪影 / Paper Cut

## 一句话理解

使用纸张层叠、轻微纹理和阴影表现手作拼贴感。

## 适合什么页面

- 营销活动页
- 个人作品集
- 移动端首页

## 不适合什么页面

- 超高密度表格
- 复杂权限后台

## 7 维度拆解

- 形状：不规则、小圆角。形状以不规则、小圆角为主，用来控制风格识别度。
- 排版：手写、无衬线。排版以手写、无衬线为主，用来控制风格识别度。
- 光影：硬投影。光影以硬投影为主，用来控制风格识别度。
- 空间：多层深度、不对称。空间以多层深度、不对称为主，用来控制风格识别度。
- 动效：平滑缓动。动效以平滑缓动为主，用来控制风格识别度。
- 色彩：暖色、多彩。色彩以暖色、多彩为主，用来控制风格识别度。
- 质感：纸张、粗糙。质感以纸张、粗糙为主，用来控制风格识别度。

## 配色方案

- background / 背景色：#FAF3DD
- primary / 主色：#2D2A26
- accent / 强调色：#E76F51
- surface / 表面色：#F4A261

## CSS 实现要点

- 纸片剪影 核心容器：`.sv-paper-cut {
  background: #FFF8E7;
  color: #2D2A26;
  border: 1px solid rgba(45,42,38,.12);
  border-radius: 14px;
  box-shadow: 10px 12px 0 rgba(45,42,38,.12);
}`

## AI Prompt 写法

请使用 Paper Cut / 纸片剪影 风格实现页面。核心视觉：使用纸张层叠、轻微纹理和阴影表现手作拼贴感。。请使用 纸张、拼贴、暖色、层叠、手作，配色以 #FAF3DD、#2D2A26、#E76F51、#F4A261 为主，CSS 方向包含 radius 14px、shadow 10px 12px 0 rgba(45,42,38,.12)、border 1px solid rgba(45,42,38,.12)。

关键词：Paper Cut 纸片剪影，纸张，拼贴，暖色，层叠，手作

## 常见错误

- 只套用颜色，没有同步 不规则、小圆角、手写、无衬线 等形态特征。
- 在 超高密度表格、复杂权限后台 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
