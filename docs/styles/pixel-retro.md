# 像素复古 / Pixel Retro

## 一句话理解

像素边框、硬切色块和低分辨率视觉带来游戏机年代感。

## 适合什么页面

- 营销活动页
- 个人作品集
- 开发者工具

## 不适合什么页面

- 强留白品牌页

## 常见错误

- 只套用颜色，没有同步 像素化、直角、等宽、硬投影 等形态特征。
- 在 极简作品集、强留白品牌页 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
