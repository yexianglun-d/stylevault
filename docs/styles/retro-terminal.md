# 复古终端 / Retro Terminal

## 一句话理解

CRT 绿字、扫描线和低亮度背景表达老式计算机感。

## 适合什么页面

- 开发者工具
- 文档站
- 数据仪表盘

## 不适合什么页面

- 极简作品集
- 强留白品牌页

## 7 维度拆解

- 形状：直角。形状以直角为主，用来控制风格识别度。
- 排版：等宽。排版以等宽为主，用来控制风格识别度。
- 光影：发光。光影以发光为主，用来控制风格识别度。
- 空间：密集、分栏。空间以密集、分栏为主，用来控制风格识别度。
- 动效：机械步进。动效以机械步进为主，用来控制风格识别度。
- 色彩：单色、冷色。色彩以单色、冷色为主，用来控制风格识别度。
- 质感：条纹、噪点。质感以条纹、噪点为主，用来控制风格识别度。

## 配色方案

- background / 背景色：#020403
- primary / 主色：#00FF66
- accent / 强调色：#003B1F
- surface / 表面色：#C8FFD8

## 常见错误

- 只套用颜色，没有同步 直角、等宽、发光、密集 等形态特征。
- 在 极简作品集、强留白品牌页 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
