# 拟物质感 / Skeuomorphic

## 一句话理解

用高光、阴影、纹理和材质模拟现实物体触感。

## 适合什么页面

- 移动端首页
- 开发者工具
- 营销活动页

## 不适合什么页面

- 超高密度表格
- 复杂权限后台

## 7 维度拆解

- 形状：小圆角。形状以小圆角为主，用来控制风格识别度。
- 排版：无衬线。排版以无衬线为主，用来控制风格识别度。
- 光影：金属高光、内阴影。光影以金属高光、内阴影为主，用来控制风格识别度。
- 空间：多层深度。空间以多层深度为主，用来控制风格识别度。
- 动效：机械步进。动效以机械步进为主，用来控制风格识别度。
- 色彩：金属、对比。色彩以金属、对比为主，用来控制风格识别度。
- 质感：金属、光滑。质感以金属、光滑为主，用来控制风格识别度。

## 常见错误

- 只套用颜色，没有同步 小圆角、无衬线、金属高光、内阴影 等形态特征。
- 在 超高密度表格、复杂权限后台 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
