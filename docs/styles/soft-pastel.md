# 柔和彩色 / Soft Pastel

## 一句话理解

低饱和粉彩、圆润卡片和轻量插画感建立亲和体验。

## 适合什么页面

- 移动端首页
- 登录页
- 注册页
- 营销活动页

## 不适合什么页面

- 超高密度表格
- 复杂权限后台

## 7 维度拆解

- 形状：大圆角。形状以大圆角为主，用来控制风格识别度。
- 排版：无衬线、均匀层级。排版以无衬线、均匀层级为主，用来控制风格识别度。
- 光影：柔和弥散。光影以柔和弥散为主，用来控制风格识别度。
- 空间：适中。空间以适中为主，用来控制风格识别度。
- 动效：平滑缓动。动效以平滑缓动为主，用来控制风格识别度。
- 色彩：低饱和、多彩。色彩以低饱和、多彩为主，用来控制风格识别度。
- 质感：光滑。质感以光滑为主，用来控制风格识别度。

## 配色方案

- background / 背景色：#FFF7FB
- primary / 主色：#F9A8D4
- accent / 强调色：#93C5FD
- surface / 表面色：#86EFAC

关键词：Soft Pastel 柔和彩色，粉彩，柔和，圆润，浅色，亲和

## 常见错误

- 只套用颜色，没有同步 大圆角、无衬线、均匀层级、柔和弥散 等形态特征。
- 在 超高密度表格、复杂权限后台 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
