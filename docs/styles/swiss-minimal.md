# 瑞士极简 / Swiss Minimal

## 一句话理解

通过网格、留白、清晰字体和克制色彩建立理性秩序。

## 适合什么页面

- 文档站
- SaaS 官网
- 定价页
- 个人作品集

## 不适合什么页面

- 超高密度表格
- 复杂权限后台

## 7 维度拆解

- 形状：直角、小圆角。形状以直角、小圆角为主，用来控制风格识别度。
- 排版：无衬线、均匀层级。排版以无衬线、均匀层级为主，用来控制风格识别度。
- 光影：无阴影。光影以无阴影为主，用来控制风格识别度。
- 空间：极多留白、网格。空间以极多留白、网格为主，用来控制风格识别度。
- 动效：快速。动效以快速为主，用来控制风格识别度。
- 色彩：双色、低饱和。色彩以双色、低饱和为主，用来控制风格识别度。
- 质感：无纹理。质感以无纹理为主，用来控制风格识别度。

## 配色方案

- background / 背景色：#F7F5EF
- primary / 主色：#111111
- accent / 强调色：#D6382D
- surface / 表面色：#D9D2C3

## CSS 实现要点

- 瑞士极简 核心容器：`.sv-swiss-minimal {
  background: #FFFCF5;
  color: #111111;
  border: 1px solid #D9D2C3;
  border-radius: 6px;
  box-shadow: 0 18px 40px rgba(17,17,17,.08);
}`

关键词：Swiss Minimal 瑞士极简，极简，网格，浅色，秩序，低饱和

## 常见错误

- 只套用颜色，没有同步 直角、小圆角、无衬线、均匀层级 等形态特征。
- 在 超高密度表格、复杂权限后台 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
