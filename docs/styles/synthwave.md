# 合成波 / Synthwave

## 一句话理解

紫粉霓虹、夕阳渐变和网格透视构成复古未来氛围。

## 适合什么页面

- 营销活动页
- 个人作品集

## 不适合什么页面

- 超高密度表格
- 复杂权限后台

- 形状：小圆角。形状以小圆角为主，用来控制风格识别度。
- 排版：装饰体、大标题主导。排版以装饰体、大标题主导为主，用来控制风格识别度。
- 光影：发光。光影以发光为主，用来控制风格识别度。
- 空间：网格、居中。空间以网格、居中为主，用来控制风格识别度。
- 动效：平滑缓动、慢速。动效以平滑缓动、慢速为主，用来控制风格识别度。
- 色彩：高饱和、渐变。色彩以高饱和、渐变为主，用来控制风格识别度。
- 质感：发光边框、网格。质感以发光边框、网格为主，用来控制风格识别度。

## 常见错误

- 只套用颜色，没有同步 小圆角、装饰体、大标题主导、发光 等形态特征。
- 在 超高密度表格、复杂权限后台 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
