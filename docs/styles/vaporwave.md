# 蒸汽波 / Vaporwave

## 一句话理解

粉紫渐变、古典元素和低保真图形构成互联网怀旧感。

## 适合什么页面

- 个人作品集
- 营销活动页

## 不适合什么页面

- 超高密度表格
- 复杂权限后台

## 7 维度拆解

- 形状：直角、小圆角。形状以直角、小圆角为主，用来控制风格识别度。
- 排版：装饰体、大标题主导。排版以装饰体、大标题主导为主，用来控制风格识别度。
- 光影：发光、硬投影。光影以发光、硬投影为主，用来控制风格识别度。
- 空间：不对称、多层深度。空间以不对称、多层深度为主，用来控制风格识别度。
- 动效：慢速。动效以慢速为主，用来控制风格识别度。
- 色彩：渐变、高饱和。色彩以渐变、高饱和为主，用来控制风格识别度。
- 质感：噪点、发光边框。质感以噪点、发光边框为主，用来控制风格识别度。

## 常见错误

- 只套用颜色，没有同步 直角、小圆角、装饰体、大标题主导 等形态特征。
- 在 超高密度表格、复杂权限后台 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
