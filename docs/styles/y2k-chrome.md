# Y2K 铬感 / Y2K Chrome

## 一句话理解

铬色、泡泡形状、亮粉亮蓝和早期互联网质感。

## 适合什么页面

- 营销活动页
- 个人作品集
- 移动端首页

## 不适合什么页面

- 超高密度表格
- 复杂权限后台

## 常见错误

- 只套用颜色，没有同步 全圆角、有机曲线、装饰体、大标题主导 等形态特征。
- 在 超高密度表格、复杂权限后台 场景里强行使用，导致可读性或维护成本下降。
- Prompt 只写风格名，没有写清楚配色、圆角、阴影、排版、动效和 CSS 方向。
